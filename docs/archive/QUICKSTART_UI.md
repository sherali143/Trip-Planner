# 🚀 QUICK START - AI Trip Planner UI

## Start the UI (Choose One):

### Method 1: Double-Click (Windows)
```
Double-click: run_ui.bat
```

### Method 2: Command Line
```bash
streamlit run app.py
```

## What Happens:
1. Browser opens at http://localhost:8501
2. Answer 8 questions one by one
3. Click "Generate My Trip Itinerary"
4. Wait 2-5 minutes
5. View & download your complete trip plan!

## Features:
✅ One question at a time (no overwhelm!)
✅ Progress tracking with checklist
✅ Beautiful conversation interface
✅ Complete itinerary with all details
✅ Download button for your plan
✅ Start over to plan multiple trips
